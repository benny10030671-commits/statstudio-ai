用自然語言，指揮你的統計工作室。

StatStudio 提供 MCP 工具，讓 Codex 讀取資料欄位、執行統計並解讀結果。統計計算在本機執行；MCP 工具會將欄位資訊、前 10 筆資料預覽與分析結果傳回連接的 AI。此頁提供連接方式與指令範例；對話在你使用的 AI 應用程式進行。

1

在安裝本工具的終端機執行

python -m statstudio install-mcp

使用已安裝 StatStudio 的 Python 環境。完成後，重新啟動 Codex，使其載入 MCP 設定。

2

把問題交給 Codex

先請 AI 檢查欄位與遺漏值，再確認方法、分析假設與結果。檔案路徑必須是目前電腦上的路徑。
